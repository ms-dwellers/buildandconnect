# Demo accounts

[accounts.csv](accounts.csv) contains the fictional account roster for the
production demo: 25 requesters and 25 developers, all using
`<username>@buildandconnect.work` addresses. The roster deliberately excludes
passwords and other credentials.

The dataset includes 25 developer profiles with skills, interests, availability,
work preferences, and 50 portfolio examples; 50 project opportunities (33 paid,
17 volunteer); and 25 small local requests. Each requester owns two opportunities
and one local request. All map pins are Calgary neighborhood centers, and every
profile and listing is labeled fictional.

The full credential CSV is stored only in the operator's private, ignored
`.demo/production-2026-11-08/accounts.csv`. Do not upload that file to GitHub,
attach it to an issue, or copy its credentials into documentation.
